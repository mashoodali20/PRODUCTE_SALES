# PRODUCTE_SALES
This project focuses on analyzing product sales data using SQL and Power BI. The main objective is to extract meaningful insights from raw data and present them through an interactive dashboard.

The dataset includes information such as product names, categories, prices, quantities, customer cities, and order dates. Using SQL queries, key business questions were answered, including total sales, top-selling products, and sales trends.

The Power BI dashboard visually represents these insights using charts like bar graphs, pie charts, and line charts. It helps in identifying high-performing categories, top cities, and monthly sales patterns.

Overall, this project demonstrates how data analytics can be used to support business decisions and improve performance.
